# Read the updated notice accurately

Status: AI draft · awaiting responsible review. Prepared: 3 October 2026.

**LES-02 · ages 13–15 (proposed group) · 45 minutes (design estimate, not measured).**

Compare two fictional notices, distinguish explicit information from assumptions, and ask for clarification when information is missing.

## Separate materials before distribution

**This is a facilitator pack; do not distribute it in full to learners.** Notes and rubric contain answers. Use the [learner handout](handout-02.md) for steps 1–6, releasing each part at its intended step. Show the sample AI response only at step 2 and source cards only at step 4. Collect/close previous work and sources before distributing the [separate independent task](transfer-02.md). Never print answers/rubric on its reverse.

## Facilitator notes

All club names, rooms and notices are fictional. Original answers: Paper Room, 09:30, registration in advance; cost unknown. Allow “not enough information”. This is not a web fact-checking lesson.

Before rehearsal, read the full lesson, try it yourself and select learner/observer roles. A real educator must review difficulty and wording before use with children. Use the [review sheet](../templates/curriculum-review.md); do not assign a reviewer's name without their actual review.

## Comparison cards · open only at the comparison step

### Notice A · team-authored, entirely fictional

Mầm Lá Club is holding a workshop in the Wood Room, starting at 09:00. Participants must register with the facilitator before the session. This notice does not state the cost.

### Notice B · fictional update

The Mầm Lá Club workshop moves to the Paper Room and starts at 09:30. Notice B replaces the time and location in A; everything else in A remains unchanged. There is no new information about the cost.

## Draft rubric · facilitator only

The facilitator compares the work with the fictional texts, paying attention to missing information. Score manually; citing a text is not the same as verifying a real-world event.

### Verification

0: accepts the summary without comparison. 1: opens sources but does not find supporting information. 2: finds the updated time/location but overlooks the retained registration requirement or guesses the cost. 3: uses A/B and the update rule, retains registration and records the cost as unknown.

Score 0 / 1 / 2 / 3 / unassessed: ____ · Evidence: ____ · Assistance: ____

### Explanation

0: copies results or explains against the sources. 1: names a source. 2: explains changes but omits retained information or limits. 3: explains what changes and what stays, and why the cost cannot be concluded.

Score 0 / 1 / 2 / 3 / unassessed: ____ · Evidence: ____ · Assistance: ____

### Independent performance

0: no work or conclusions contradict the texts. 1: one correct fact. 2: correct location/time/item but does not identify missing registration information. 3: independently identifies Room B, 10:00, a notebook and unknown registration, with supporting reasoning.

## Why there is a transfer task

C/D is shorter than A/B to reduce reading demand. The missing-information category changes to registration. Results describe one fictional text-comparison task only.

Keep source cards, fixtures, facilitator answers and previous work out of independent-task view. If clarifying instructions is necessary, record the exact help and mark the changed conditions.
