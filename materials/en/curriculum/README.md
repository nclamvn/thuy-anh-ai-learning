# Draft curriculum · three ways to check for yourself

Status: AI draft · awaiting responsible review. Prepared: 3 October 2026.

These lessons share a process but require three different checks. Use only for adult rehearsals until an educator reviews difficulty, language, rubric and delivery conditions.

| Lesson | Learner action | Limit of the assessment |
|---|---|---|
| [Measure what the AI claims](lesson-01.md) | Recalculate; distinguish quantities | Near-structure task, not long-term retention |
| [Read the updated notice accurately](lesson-02.md) | Compare two texts; state unknowns | Fictional documents, not real-world fact-checking |
| [A question you can test](lesson-03.md) | Isolate a variable; design a comparison | Planning on paper, no experiment measured |

Machine-readable [lessons.json](../../curriculum/lessons.json) contains eight instructions per lesson, team-authored cards, deliberately incorrect fixtures, a three-axis rubric and transfer notes. Source IDs inform methodological choices, not every authored detail's validity.

## Choosing a lesson

Ask a reviewer about prerequisites and goals; age alone does not determine suitability. Choose one lesson for the first rehearsal. LES-01 has explicit calculations that expose delivery errors; LES-02 tests recording textual evidence; LES-03 tests support when several reasonable plans are possible.

## Lesson lifecycle

Draft → [review](../templates/curriculum-review.md) → adult rehearsal → record issues and create a revised version → responsible person decides the next step. Manually entered local comments do not authenticate identity or approve use with children. Started sessions retain their lesson snapshots.

Never treat sample scores as actual results. Keep sources, session counts, assistance and missing information separate using the [observer sheet](../templates/observer-sheet.md).
