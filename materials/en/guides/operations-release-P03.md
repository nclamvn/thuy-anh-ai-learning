## Incident loop

Pause on lost work, wrong source, independent-task key leakage or unknown data destination. Preserve answers/original backup/message; record time/step/version/viewport/data kind. Separate OBSERVED from interpretation. Avoid repeated retries/clearing state before saving. Owner triages impact → workaround/fix → affected-case checks → closure/defer with scope. No whole-system safety claim.

Include only allowed source/app/docs/public research/SOT/delivery; exclude environment/secrets/private backup/QA/browser data. Verify manifest/hash, extract to separate test directory, start localhost, read VI/EN and export/restore synthetic data. Historical ZIP/checks stay historical.
