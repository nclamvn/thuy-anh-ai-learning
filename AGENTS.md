# Project collaboration rules

This public distribution supports local adult rehearsal with synthetic data. Keep VI/EN presentation and immutable session snapshots; never invent educational review, participant consent, outcome measurements or authenticated human approval. Learner preview is not access control. Fixtures must remain labelled synthetic and the live provider must remain inactive until an explicit responsible decision.

Workflow: requirements → implementation TIP → build/test → completion → independent verification. Separate cited external findings, owner decisions, AI proposals and synthetic examples. Preserve provenance and uncertainty; comparisons must not claim unmeasured educational effectiveness.

Run `python3 -B tools/check_public.py` for the public references-only profile. Full raw-capture validation is unavailable in this distribution; original strict checks intentionally fail without the lawfully held, hash-matching corpus. Do not weaken them, automatically redownload sources or fabricate capture files. Source catalog/resources are generated counterparts; reviewed material edits require the original corpus-aware compiler, or an explicitly designed new build protocol. Refresh `PUBLIC-MANIFEST.json` only after reviewing intended source changes.

Never commit localStorage backups, real participant data, API keys, environment files, private conversation or raw copyrighted captures. Project license remains undecided; retain font OFL and all source citations. Publication authorization is not permission for deployment, live AI calls or a child pilot.
