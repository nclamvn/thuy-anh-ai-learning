# Local project kit · start here

Status: AI drafts and local operating guides. Prepared: 3 October 2026. Materials await educational review; all DEMO roles/work/situations are fictional. No external groups or invitations were created or sent.

## Choose a working path

- **Clarify the project:** read the [brief](project-brief.md), note unknowns and assign the [human work](guides/human-handoff.md).
- **Rehearse one session:** choose one [draft lesson](curriculum/README.md), use the [session plan](templates/session-plan.md) and [45-minute guide](guides/facilitator-rehearsal.md). Do not distribute facilitator answer packs to learners.
- **Author and review:** use canonical lessons.json and [review sheet](templates/curriculum-review.md), then create a new version. A local comment is not educational approval.
- **Record and decide:** keep [observations](templates/observer-sheet.md), [evidence](templates/evidence-capture.md), [issues](templates/issue-risk-log.md) and [decisions](templates/decision-record.md) distinct.
- **Operate:** read [quickstart](guides/operator-quickstart.md), [backup](guides/backup-and-recovery.md) and [local release](guides/release-checklist.md).
- **Trace research and benchmark:** [source index](research/source-index.md), [scoring guide](benchmark/scoring-guide.md). Live measurements are absent; fields stay null until observed.

## Machine-readable sources and generated copies

[lessons.json](../curriculum/lessons.json) contains three sample lessons and authored English counterparts, without invented scores/reviewers. `catalog.json` is the source allowlist; workspace compiler generates `app/resources/`. Edit sources, never generated copies as substitutes. Fingerprints identify the generated source content.

Links resolve within the mirrored materials library or public sources; files outside materials are provenance to open in the workspace. No QA backups, private conversations or family information belong in the catalogue.

## Using templates with actual information

Copy a template, retain draft status until the responsible person reviews, and replace fictional examples only with actual permitted information. Write unknown where evidence is absent. Agree data-use scope; do not name real people as having accepted a role or consented without confirmation. AI does not send posts, recruit, make educational decisions or confirm access rights.
